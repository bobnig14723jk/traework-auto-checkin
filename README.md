# 🍊 橙子签到 - TraeWork CN 自动签到工具

每天自动帮你领取 TraeWork CN 200积分，图形界面，一键操作，快速稳定！

## ✨ 功能特点

- 🖼️ **清爽图形界面** - 所有功能一个窗口搞定，没有复杂标签页
- 🚀 **闪电快速签到** - 极速点击，整个签到过程不到2秒
- 🎯 **傻瓜式校准** - 右下角小窗提示，鼠标移过去点确认就行，不用切窗口
- ⏰ **定时自动签到** - 下拉选时间，一键启用每天自动领积分
- 📋 **带日期日志** - 每一步操作都有详细记录，带日期时间戳
- 🍊 **可爱橙子图标** - 看着就心情好
- 🖥️ **高DPI支持** - 完美适配各种缩放比例的屏幕

## 🚀 快速开始

### 直接下载使用（推荐）

1. 前往 [Releases](https://github.com/bobnig14723jk/traework-auto-checkin/releases) 页面下载最新版本 `橙子签到.exe`
2. 放到任意文件夹，双击运行
3. **首次使用必须先校准坐标**：点击「开始校准坐标」按钮，按照提示操作
4. 校准完成后点击「立即签到」即可
5. （可选）选择时间后点击「启用自动签到」，设置每天自动签到

### 从源码运行

```bash
# 安装依赖
pip install pyinstaller

# 打包成exe
python -m PyInstaller --onefile --windowed --icon=orange.ico --name=橙子签到 main.py -y

# 打包后exe在dist目录下
```

或者直接用Python运行：
```bash
python main.py
```

## 📖 使用说明

### 第一步：坐标校准（重要！首次必做）

因为每个人的屏幕分辨率、缩放比例不同，首次使用前需要校准2个坐标：

1. 双击打开 `橙子签到.exe`
2. 点击「开始校准坐标」按钮
3. 程序会自动打开并最大化 TraeWork
4. **第1步**：右下角出现黄色提示窗，把鼠标移到 TraeWork 左下角【头像】上，然后点提示窗上的「✓ 确认位置」按钮
5. 程序自动点击头像打开侧边栏
6. **第2步**：右下角出现蓝色提示窗，把鼠标移到【每日签到领200积分】按钮上，然后点「✓ 确认位置」按钮
7. 程序自动测试点击并保存配置，校准完成！

> 💡 **小技巧**：不需要按Alt+Tab切换窗口，也不需要点TraeWork窗口，直接移动鼠标过去，然后点右下角的确认按钮就行！按钮默认有焦点，也可以按回车键触发。

### 第二步：手动签到测试

校准完成后，点击大大的绿色「立即签到」按钮，测试一下是否能正常签到。整个过程飞快，鼠标点完立即回到原位。

### 第三步：设置每日自动签到（可选）

1. 在「每日自动签到」区域选择想要的时间（小时:分钟）
2. 点击「启用自动签到」按钮
3. 弹出管理员权限请求时点「是」即可
4. 看到状态变成"自动签到：已启用"就成功了

**注意**：
- 如果到点时电脑关机/休眠，下次开机后不会补签（Windows任务计划程序的限制）
- 电脑必须是解锁状态（锁屏下Windows禁止模拟鼠标点击）
- 想取消自动签到，点「取消自动」按钮即可

## ❓ 常见问题

**Q: 点击位置不对怎么办？**
> 重新点一次「开始校准坐标」就行，30秒搞定。

**Q: 签到时会占用我的鼠标吗？**
> 会临时移动鼠标大约1-2秒，点击完成后立即放回原位，几乎无感知。建议把定时时间设为你刚开始用电脑的时间。

**Q: TraeWork更新后界面变了点不到了？**
> 重新运行校准一次就行。

**Q: 杀毒软件报毒？**
> 这是Python用PyInstaller打包的exe，没有任何恶意代码。如果报毒请添加信任，或者自行从源码打包。

**Q: 定时任务没运行？**
> 检查一下：1）电脑是否开机且未锁屏；2）任务是否创建成功（看界面上的状态显示）；3）可以尝试重新启用一次。

**Q: 支持TraeCode CN吗？**
> 目前主要针对TraeWork CN，TraeCode界面可能不同，但理论上也可以用，需要自行校准坐标。

## ⚠️ 注意事项

- 签到时电脑不能是锁屏状态（锁屏后Windows禁止模拟鼠标点击）
- 运行签到程序时TraeWork窗口会自动最大化
- 本工具仅为方便使用，请遵守TraeWork相关规定
- 如界面更新点不到了，重新校准一次坐标即可
