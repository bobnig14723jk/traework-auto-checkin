# 🍊 TraeWork CN 自动签到工具

每天自动帮你领取 TraeWork CN 200积分，带图形界面！一个文件搞定所有功能，简单方便~

## ✨ 功能特点

- 🖼️ **图形界面** - 所有功能一个窗口搞定，清爽易用
- 🚀 **一键签到** - 点一下大按钮就完成，鼠标秒归位
- 🎯 **可视化校准** - 向导式引导，2步完成坐标校准
- ⏰ **定时设置** - 选择时间，一键启用每日自动签到
- 📋 **实时日志** - 每一步操作都有记录，出问题一目了然
- 🍊 **橙子图标** - 可爱的橙子图标，看着就开心（已内嵌，无需额外文件）
- 🖥️ **高DPI支持** - 完美适配各种缩放比例的屏幕
- 📦 **单文件** - 整个程序就一个 `main.py`，下载即用，简单方便！

## 🚀 快速开始

### 方式一：直接运行 Python 脚本（最简单）

1. 下载 `main.py` 到任意文件夹
2. 双击运行（或者命令行执行 `python main.py`）
3. **首次使用必须先校准坐标**：点击「开始校准坐标」按照提示操作
4. 校准完成后点击「立即签到」即可
5. （可选）设置时间后点击「启用自动签到」即可每天自动签到

### 方式二：打包成 exe 使用

```bash
# 安装 pyinstaller
pip install pyinstaller

# 打包成单文件 exe（图标已内嵌，不需要额外文件）
pyinstaller -F -w -n "橙子签到" main.py

# 打包后 exe 在 dist 目录下，双击即可运行
```

## 📖 使用说明

### 第一步：坐标校准（重要！首次必做）

因为每个人的屏幕分辨率、缩放比例、TraeWork窗口大小可能不同，首次使用前需要校准坐标：

1. 运行 `main.py`（或者打包后的 exe）
2. 点击「开始校准坐标」按钮
3. 按照弹窗提示操作：
   - 程序会自动最大化TraeWork窗口
   - **第1步**：把鼠标移动到 TraeWork 左下角的【头像】上（不要点击），点击提示窗口的「确认位置」
   - 程序会自动点开侧边栏
   - **第2步**：把鼠标移动到【每日签到领200积分】按钮上（不要点击），点击提示窗口的「确认位置」
4. 程序会自动测试点击并保存配置，完成！

**提示**：校准过程中按回车键也可以确认位置哦~

### 第二步：手动签到测试

校准完成后，点击大大的「立即签到」按钮，测试一下是否能正常签到。整个过程不到2秒，鼠标点完立即回到原位。

### 第三步：设置每日自动签到（可选）

1. 在「每日自动签到」区域选择你想要的时间（建议选你刚开电脑的时间，比如9:00）
2. 点击「启用自动签到」按钮
3. 弹出管理员权限请求时点「是」即可

**注意**：
- 如果到点时电脑关机/休眠，下次开机后会自动补签
- 电脑必须是解锁状态（锁屏下Windows禁止模拟鼠标点击）
- 想取消自动签到，点击「取消自动」按钮即可

## ❓ 常见问题

**Q: 点击位置不对怎么办？**
> 重新点一次「开始校准坐标」就行，2分钟搞定。

**Q: 签到时会占用我的鼠标吗？**
> 会临时移动鼠标大约1-2秒，点击完成后立即放回原位，几乎无感知。建议把定时时间设为你刚开始用电脑的时间。

**Q: TraeWork更新后界面变了点不到了？**
> 重新运行校准一次就行。

**Q: 杀毒软件报毒？**
> 这是Python用PyInstaller打包的exe，没有任何恶意代码。如果报毒请添加信任，或者直接运行源码 `main.py`。

**Q: 定时任务没运行？**
> 检查一下：1）电脑是否开机且未锁屏；2）任务是否创建成功（看界面上的状态显示）；3）可以尝试重新点击「启用自动签到」。

**Q: 支持TraeCode CN吗？**
> 目前主要针对TraeWork CN，TraeCode界面可能不同，但理论上也可以用，需要自行校准坐标。

## ⚠️ 注意事项

- 签到时电脑不能是锁屏状态（锁屏后Windows禁止模拟鼠标点击）
- 运行签到程序时TraeWork窗口会自动最大化
- 本工具仅为方便使用，请遵守TraeWork相关规定
- 如界面更新点不到了，重新校准一次坐标即可
