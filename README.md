# 🍊 TraeWork CN 自动签到工具

每天自动帮你领取 TraeWork CN 200积分，不用再手动点签到啦！

## ✨ 功能特性

- 🖱️ **自动点击签到** - 启动后自动打开/切换到TraeWork，点击头像→点击签到按钮
- ⚡ **极速完成** - 整个点击过程不到1秒，鼠标点击完立即归位
- 🖥️ **高DPI支持** - 完美适配各种缩放比例的屏幕，坐标不会偏移
- 🕘 **每日定时** - 创建计划任务后每天早上9点自动签到，电脑没开则开机后补签
- 📝 **日志记录** - 自动记录每次签到结果，方便排查问题
- 🍊 **可爱图标** - 橙子图标，放在桌面上心情好~

## 🚀 快速开始

### 方式一：直接下载使用（推荐）

1. 前往 [Releases](https://github.com/bobnig14723jk/traework-auto-checkin/releases) 页面下载最新版本
2. 解压到任意文件夹
3. **首次使用必须先校准坐标**：双击运行 `CalibrateCoords.exe`，按照提示操作（2步搞定）
4. 双击 `OrangeCheckin.exe` 即可手动签到
5. （可选）右键以管理员身份运行 `setup_task.bat` 创建每日定时任务

## 📖 使用说明

### 坐标校准（重要！首次必做）

因为每个人的屏幕分辨率、缩放比例、TraeWork窗口大小可能不同，首次使用前需要校准坐标：

1. 确保 TraeWork CN 已安装
2. 双击运行 `CalibrateCoords.exe`
3. **第1步**：把鼠标移到左下角**头像**上（不要点击），按Alt+Tab切回黑窗口按回车
4. 程序会自动点开侧边栏
5. **第2步**：把鼠标移到**每日签到领200积分**按钮上（不要点击），切回黑窗口按回车
6. 程序会自动测试点击并保存配置，完成！

### 设置自动签到

校准完成后，右键以**管理员身份**运行 `setup_task.bat`，即可创建Windows计划任务：
- 每天早上 9:00 自动运行签到
- 如果9点时电脑关机/休眠，下次开机后会自动补签
- 想取消自动签到，运行 `remove_task.bat` 即可

### 手动签到

校准完成后，任何时候双击 `OrangeCheckin.exe` 即可立即签到。你也可以给它创建快捷方式放到桌面。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `OrangeCheckin.exe` | 🍊 签到主程序，双击运行 |
| `CalibrateCoords.exe` | 🎯 坐标校准工具，首次使用必须运行 |
| `setup_task.bat` | ⏰ 以管理员运行，设置每日定时签到 |
| `remove_task.bat` | ❌ 取消每日定时签到 |
| `checkin_config.json` | ⚙️ 配置文件（校准后自动生成） |
| `traework-checkin.log` | 📋 签到日志（每次运行自动生成） |

## ❓ 常见问题

**Q: 点击位置不对怎么办？**
> 重新运行 `CalibrateCoords.exe` 校准一次坐标即可。

**Q: 签到时会占用我的鼠标吗？**
> 会临时移动鼠标大约1秒，点击完成后立即放回原位，几乎无感知。建议把定时时间设为你刚开始用电脑的时间（比如9点）。

**Q: TraeWork更新后界面变了点不到了？**
> 重新运行校准工具就行。

**Q: 支持TraeCode CN吗？**
> 目前只针对TraeWork CN，TraeCode的界面可能不同，但理论上也可以用，需要自行校准坐标。

**Q: 杀毒软件报毒？**
> 这是Python打包的exe，没有任何恶意代码。如果报毒请添加信任，或者自行从源码打包。

## ⚠️ 注意事项

- 签到时电脑不能是锁屏状态（锁屏后Windows禁止模拟鼠标点击）
- 运行签到程序时TraeWork窗口会自动最大化
- 本工具仅为方便使用，请遵守TraeWork相关规定
